有画布时：标题行入口 + 过程区浮层

当对话页面拆出画布后，画布专注当前产物；同一排资源 icon 仍和对话标题平行，点击后在 FRIDAY 过程区上方以浮层显示共用资源窗口。

资源
1. 最左常驻导航

搜索、项目、团队、日历、模块、SOUL 和设置固定在最左侧；团队、日历先占位，点击项目后第二层菜单显示全部项目。

2. 项目进入项目主页

第二层菜单只做项目切换；点击项目后先进入项目主页，再选择对话进入当前画布页。

3. 对话页拆出画布

画布和右侧过程区属于同一个对话页面；画布只是当前对话里的可操作页面。

4. 最右侧是 FRIDAY 对话

完整历史、过程、工具调用、确认事项和继续输入都固定在右侧，不被资源入口替代。
