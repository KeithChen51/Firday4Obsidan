# 来自制作组 · From the Studio

## 这个栏目是什么

来自制作组是 F.R.I.D.A.Y 面向用户的公开栏目，不是技术文档区，也不是内部开发资料库。它想回答的问题只有一个：F.R.I.D.A.Y 在如何成长，以及我们为什么这样做。

这里记录的是产品真实的演进过程：每一次迭代背后的判断、每一个设计决策的来由、每一项研究的结论。我们希望用户不只是使用这个工具，也能了解它是怎么被思考出来的。

## 三个模块

### 一、Changelog

这里收录 F.R.I.D.A.Y 所有版本的更新内容，包括新功能、体验改进和问题修复。它不只是一份变更列表，我们会尽量说清楚为什么做这件事，而不只是做了什么。

### 二、Study with F.R.I.D.A.Y

这里是制作组对外分享的研究、思考与判断。开发 F.R.I.D.A.Y 的过程中，值得认真对待的问题、方案取舍和研究结论，会整理后公开放在这里。

每一篇都是我们和 Friday 一起学习的过程——有时候是一个已经想清楚的决策，有时候是一个还在探索中的问题，有时候只是一段值得记录下来的观察。

### 三、从这里开始 · Start Here

这是整个栏目的导览入口。它会说明这里有什么、不同内容适合什么阅读目的，以及想快速了解或深入阅读时该从哪里开始。

## 整体基调

来自制作组不追求完整，也不追求权威。它更像是一本持续更新的工作日志：有时候是一个已经想清楚的决策，有时候是一个还在探索中的问题，有时候只是一段值得记录下来的观察。我们希望它呈现的是真实的制作过程，而不是经过打磨的产品叙事。
