# 05 和 FRIDAY 对话

对话页是最常用的入口。好的输入会让 FRIDAY 更快进入正确上下文。

![[assets/05-02-chat-composer.png|760]]

## 先从小任务开始

刚开始使用时，先选一个范围清楚的小任务：

```text
总结当前笔记，并列出三个行动项。
```

```text
帮我检查这个方案里最不清楚的地方。
```

```text
把当前项目这周最重要的风险整理成表格。
```

这类任务容易确认结果，也能帮你判断当前项目和模型是否配置正确。

## 输入框怎么读

输入框下方有几类控制：

| 控件 | 作用 |
| --- | --- |
| 模型选择 | 临时切换当前 Soul 使用的模型 |
| 权限模式 | 控制工具执行前是否需要确认 |
| `+Skill` | 插入 `/`，选择要调用的 Skill |
| `@` | 引用当前笔记、某篇笔记或文件夹 |
| 发送 | 发送当前消息 |

模型和权限的临时切换会影响当前对话体验。长期默认值可以到设置页调整。

## 普通提问

适合直接问判断、解释、总结和方案。问题越具体，FRIDAY 越容易进入正确上下文。

不推荐：

```text
优化一下。
```

更推荐：

```text
把当前笔记改成一份项目周报，保留原有标题，不要删除风险列表。
```

## 引用当前笔记

输入框支持 `@` 引用。常用方式：

- 当前笔记：让 FRIDAY 基于正在看的文件回答。
- 笔记：引用某一篇具体笔记。
- 文件夹：引用某个目录范围。

引用成功后，界面会显示已解析的文件路径。如果 FRIDAY 回答得像没看到资料，先检查引用是否解析成功，以及当前项目是否选对。

## 发送图片

如果当前模型支持视觉输入，可以用图片按钮附加截图、界面问题或图表。图片适合用来说明：

- UI 显示异常。
- 图表或白板内容。
- 纸面草图。
- 报错截图。

图片过大时会被拒绝。建议先裁剪到问题区域。

## 看懂回复

FRIDAY 的回复通常会先根据上下文解释判断，再给出操作建议。涉及工具执行时，还会出现执行摘要。

![[assets/05-02-chat-composer.png|720]]

执行摘要通常分为：

- 上下文：加载项目规则、Skill、Wiki、记忆。
- 分析：模型判断下一步。
- 执行：读取、搜索、写入或同步。
- 回复：整理最终答案。

## 工作中继续输入

FRIDAY 正在工作时，你可以继续输入下一条指令。按 Enter 后会加入队列，当前任务完成后自动继续。

适合连续工作流：

```text
先总结这篇笔记。
```

```text
总结完后，把行动项整理成任务清单。
```

> [!tip]
> 如果任务涉及修改文件，尽量说清楚目标文件、期望格式和是否允许覆盖。不要只说“优化一下”。
