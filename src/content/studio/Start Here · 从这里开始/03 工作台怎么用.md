# 03 工作台怎么用

FRIDAY 工作台是日常入口。你大部分操作都在这里完成。

![[assets/03-01-workbench-tabs.png|760]]

如果你刚安装，工作台可能先显示新手引导。完成工作范围和模型配置后，对话页会成为主要入口。

## 顶部导航

工作台分为三个页面：

- 对话：提问、引用上下文、查看工具执行。
- 同步：管理项目边界、同步状态和工作区变化。
- 工具/技能：查看 Skill、工具权限和执行能力。

如果还没有当前项目，工作台会引导你先选择工作范围。没有项目边界时，FRIDAY 不会贸然读写文件。

## 当前项目

当前项目显示在工作台顶部。它决定：

- FRIDAY 默认读取哪个项目。
- 工具写入时允许落在哪个目录。
- `@ 文件夹` 和项目知识检索的范围。
- 同步页显示哪个项目的 Git 状态。

![[assets/03-02-current-project.png|360]]

当 FRIDAY 给出的结果不符合预期时，先检查当前项目是否选对。

## 对话页

对话页包含三块：

- 顶部状态：LLM 是否已配置、当前 Soul、创建新会话。
- 消息区：用户消息、FRIDAY 回复、工具执行摘要。
- 输入区：模型选择、权限模式、`+Skill`、`@` 引用和发送按钮。

输入区的详细说明见 [[05 和 FRIDAY 对话]]。

## 同步页

同步页不是“必须配置 Git”的入口，而是查看当前项目状态的地方。它会告诉你当前项目属于哪种状态：

- 还没有项目。
- 只有本地工作范围。
- 已绑定 Git 远端。
- 存在冲突或待处理变更。

项目和同步的关系见 [[04 项目与同步]]。

## 工具/技能页

工具/技能页用于理解 FRIDAY 能调用哪些能力。这里可以查看：

- 内置工具。
- 内置 Skill。
- 外部 Skill。
- 每个 Skill 的用途说明。

你不需要在第一次使用时理解全部工具。等你开始有固定流程，再看 [[06 Skill 与斜杠命令]]。

## 临时设置

对话页可以临时切换：

- 当前 Agent 模型。
- 当前工具权限模式。

这些切换只影响当前对话上下文，不等于永久改全局默认配置。需要长期生效时，去设置页调整。

## 工具执行摘要

当 FRIDAY 调用工具时，会出现执行阶段和摘要。重点看三类信息：

- 读取了哪些上下文。
- 调用了哪些工具。
- 是否有写入、删除或同步动作等待确认。

> [!tip]
> 如果你不确定 FRIDAY 为什么这样回答，先展开工具执行摘要。那里通常能看到它实际参考了哪些资料。
