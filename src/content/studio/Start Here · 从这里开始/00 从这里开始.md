## FRIDAY 的三个核心概念

```mermaid
flowchart LR
    A["项目边界"] --> B["上下文"]
    B --> C["对话与工具执行"]
    D["模型配置"] --> C
    E["Skill / Soul"] --> C
```

项目边界决定 FRIDAY 能看哪里、写哪里。模型配置决定 FRIDAY 能不能回答。Skill 和 Soul 是在基础能力之上的增强项。

> [!tip]
> 第一次使用不要先追求“全部配置完成”。先选一个工作文件夹，再配好模型，完成第一轮对话即可。
