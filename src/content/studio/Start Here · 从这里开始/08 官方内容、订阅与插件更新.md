# 08 官方内容、订阅与插件更新

官方内容包括 Start Here、教程、图片资源、变更说明和后续制作组发布的栏目。

![[assets/00-01.png|420]]

## 官方内容放在哪里

官方内容会发布到制作组目录下。Start Here 是其中的入门指南入口。

常见内容包括：

- 新手教程。
- 配置说明。
- 工作台说明。
- 项目与同步说明。
- Skill 使用说明。
- 官方图片资源。

这些内容可以随官方发布机制更新，而不是写死在插件代码里。

## 插件内引导与 Start Here 的关系

插件内引导解决“第一公里”：

- 不依赖模型。
- 不依赖 Git。
- 不依赖官方内容刷新。
- 告诉你下一步该配置什么。

Start Here 解决“完整文档”：

- 解释每个功能为什么存在。
- 给出详细操作说明。
- 承载图片、教程和 FAQ。
- 随官方内容持续更新。

> [!important]
> 如果第一次安装后还没刷新官方内容，工作台里的引导仍然应该能出现。Start Here 不能成为唯一帮助入口。

## 订阅频道

订阅频道用于决定哪些官方栏目会进入 Vault。默认可以订阅制作组内容，也可以按需关闭某些栏目。

适合关闭订阅的情况：

- 你只想使用插件功能，不想同步官方教程。
- 某些栏目与你无关。
- 你希望手动管理官方内容。

关闭订阅不会删除你的个人项目内容。

## 内容更新

刷新官方内容后，FRIDAY 会根据发布源更新对应文件。更新内容可能包括：

- Markdown 指南。
- 图片资源。
- Changelog。
- 示例文件。

如果你修改了官方内容，刷新可能会覆盖相同路径的文件。建议把个人批注写到自己的项目目录，或复制到个人笔记再修改。

## 插件更新

插件更新和官方内容更新是两件事：

| 更新对象 | 影响 |
| --- | --- |
| 插件更新 | 更新 `main.js`、`styles.css`、`manifest.json` 等插件产物 |
| 官方内容更新 | 更新 Vault 里的指南、栏目和图片 |

插件更新后通常需要重载插件。官方内容更新后，刷新文件即可看到新内容。

## 遗留内容保护

如果旧版 `F.R.I.D.A.Y/` 下存在历史内容，FRIDAY 会尽量避免直接接管或删除。遇到提示时，先确认：

- 这些路径是不是旧项目。
- 是否已经迁移到新项目边界。
- 是否有个人笔记混在官方目录里。

> [!warning]
> 不要把个人长期内容直接写进官方内容目录。官方目录适合阅读和引用，个人项目应该放在自己的项目边界内。

遇到刷新失败或看不到订阅频道时，先看 [[09 常见问题]]。
