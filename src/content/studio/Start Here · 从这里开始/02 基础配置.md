# 02 基础配置

![[assets/01-03.png|720]]


## 第一次对话需要什么

最小可用配置是：

- 当前项目：也就是 FRIDAY 可以读写的工作范围。
- API 地址：模型网关或 OpenAI 兼容地址。
- 默认模型：工作台默认使用的模型。
- API 密钥：按你的网关要求填写，不需要时可以留空。

显示名称建议填写，但不是第一次对话的硬前置。Git 信息只在远端同步、订阅频道或插件更新需要凭据时再补。

## 用户信息

这里主要影响界面显示和 Git 行为：

| 配置           | 作用                     | 是否第一次必填 |
| ------------ | ---------------------- | ------- |
| FRIDAY 如何称呼你 | 用于工作台消息和提示             | 否       |
| Git 用户名      | 用于远端仓库认证或同步操作          | 否       |
| Git 邮箱       | 用于 Git 提交身份            | 否       |
| Git 令牌       | 用于访问需要凭据的远端仓库、订阅内容或更新源 | 否       |

如果你只是先和 FRIDAY 对话，不需要先填 Git。

## 启动入口

FRIDAY 默认会在 Obsidian 启动后自动唤醒，并打开到右侧边栏。这样新用户第一次安装后不用寻找命令，也能看到下一步该做什么。

你可以在设置中调整：

- Obsidian 启动后是否自动唤醒 FRIDAY。
- 自动打开在左侧边栏还是右侧边栏。

如果你更习惯手动打开，可以关闭自动唤醒。关闭后仍然可以通过命令面板打开 FRIDAY 工作台。

## LLM 配置

FRIDAY 支持两类接入：

- OpenAI 协议模式：填写兼容 `/v1` 或完整 `chat/completions` 的地址。
- 集团集采模式：使用内部网关和预置模型。

关键字段：

- API 地址：必填。
- API 密钥：按网关要求填写，可选。
- 默认模型：工作台默认使用的模型。
- 温度、最大 Token：不知道含义时可以留空。
- 流式输出：建议开启，回复会更及时。

## 连通测试

配置完成后，点击连通测试。常见结果：

- 已连接：模型可用；如果已经有当前项目，就可以开始对话。
- 连接失败：检查 API 地址、密钥、网络和模型名。
- 返回体字段不兼容：网关不是标准 OpenAI Chat Completions 返回格式。

> [!tip]
> 模型配置是开启 Agent 对话的必要条件，但不是使用同步页、查看项目配置和阅读官方内容的必要条件。

## 推荐初始配置

第一次使用建议：

| 配置项 | 建议 |
| --- | --- |
| 权限模式 | 标准 |
| Tool Calling | auto |
| 启用 Agent 工具运行时 | 开 |
| 启用命令执行 | 关 |
| 高级：工具循环紧急保险 | 保留默认值 |
