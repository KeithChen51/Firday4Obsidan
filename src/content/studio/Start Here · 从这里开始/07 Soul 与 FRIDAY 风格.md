# 07 Soul 与 FRIDAY 风格

Soul 定义 FRIDAY 的人格、风格和协作方式。模型决定能力边界，Soul 决定它如何表达和判断。

![[assets/08-01-soul-and-model.png|360]]

## Soul 决定什么

Soul 通常影响：

- 回答语气。
- 输出结构。
- 是否先给结论。
- 对风险和不确定性的处理方式。
- 是否偏研究、执行、复盘或写作。

同一个模型，换一个 Soul，体验可能会明显不同。

## 原生 FRIDAY

原生 FRIDAY 是默认 Soul，适合大多数场景：

- 先给结论，再展开。
- 保持克制、清晰、可执行。
- 遇到不确定信息会提示风险。
- 优先围绕当前项目边界工作。

如果你刚开始使用，建议先保留原生 FRIDAY。等你明确知道想改变什么，再新建 Soul。

## 新建 Soul

适合新建 Soul 的情况：

| 需求 | Soul 方向 |
| --- | --- |
| 帮你写教程 | 更像编辑和讲师 |
| 帮你做研究 | 更像研究助理 |
| 帮你做复盘 | 更关注事实、决策和风险 |
| 帮你写产品文档 | 更重视结构和用户语言 |

Soul 名称只负责显示，真正影响行为的是 Soul 定义。

## 写好 Soul 定义

一个可用的 Soul 定义可以包含：

- 你希望它扮演什么角色。
- 它应该如何组织回答。
- 它应该避免什么。
- 当信息不足时应该怎么处理。

示例：

```text
你是一个克制、直接的产品文档编辑。先判断用户真正要完成什么，再给出可执行内容。不要写营销腔，不要过度解释。遇到不确定信息时明确标注。
```

## 切换 Soul 与模型

对话页顶部可以快速切换当前 Soul。输入框下方可以临时切换模型。两者区别：

- Soul：影响风格和协作方式。
- 模型：影响推理、速度、视觉能力和成本。

> [!tip]
> 不建议一开始创建很多 Soul。先从原生 FRIDAY 开始，用一段时间后再根据稳定需求拆分。
