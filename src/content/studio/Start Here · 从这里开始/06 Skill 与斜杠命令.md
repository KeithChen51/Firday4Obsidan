# 06 Skill 与斜杠命令

Skill 是给 FRIDAY 的可复用工作说明。斜杠命令是你在对话里快速调用这些说明的入口。

![[assets/06-01-skill-entry.png|520]]

## 查看可用 Skill

在对话框输入：

```text
/skills
```

FRIDAY 会列出当前可用的 Skill。内置 Skill 不需要额外配置，外部 Skill 需要在设置里配置 Skill 路径。

## 调用 Skill

常见方式有两种：

- 点击 `+Skill`，让输入框插入 `/` 并打开候选。
- 直接输入 `/`，继续输入关键字筛选。

Skill 会作为上下文进入当前任务。你可以把它理解为“先告诉 FRIDAY 应该按哪套方法做事”。

## Skill 适合什么任务

适合使用 Skill 的情况：

- 每次都要按固定步骤处理。
- 需要统一输出格式。
- 需要遵守某些检查清单。
- 某个流程经常被不同项目复用。

不一定需要 Skill 的情况：

- 一次性的普通问答。
- 很短的总结或解释。
- 还没想清楚流程本身。

## 内置 Skill

内置 Skill 会随插件提供，用于覆盖常见工作：

- 写作和润色。
- 需求拆解。
- 项目总结。
- 文档整理。
- 检查和复盘。

工具/技能页可以查看每个 Skill 的用途说明。

## 自定义 Skill

自定义 Skill 通常是一个包含 `SKILL.md` 的文件夹。你可以把团队流程写进去，例如：

```text
会议纪要整理
需求评审检查
周报生成
风险复盘
```

设置好外部 Skill 路径后，FRIDAY 会扫描这些目录，并在对话里提供调用入口。
![[assets/06-02.png|720]]
## 写好 Skill 的原则

一个好 Skill 应该：

- 明确什么时候使用。
- 写清输入和输出。
- 列出必须遵守的步骤。
- 给出一两个简短示例。
- 不把所有情况都塞进去。

> [!tip]
> 如果你发现自己第三次输入同一段长提示词，就可以考虑把它整理成 Skill。
