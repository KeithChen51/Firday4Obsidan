# 09 常见问题

这页用于快速定位常见失败原因。排查时优先看三件事：当前项目、LLM 连通状态、工具执行摘要。

![[assets/01-01.png|720]]

## LLM 连不上

先检查：

- API 地址是否填写完整。
- 模型名是否存在。
- API 密钥是否需要填写。
- 网关是否支持 OpenAI Chat Completions 返回格式。
- 当前网络是否能访问网关。

如果错误提示返回体字段不兼容，通常不是密钥问题，而是接口协议不匹配。

## 工作台没有自动打开

可能原因：

- 设置里关闭了“Obsidian 启动后自动唤醒 FRIDAY”。
- Obsidian 上次关闭时工作区布局没有恢复完成。
- 插件被禁用或没有完成加载。

可以先通过命令面板运行 FRIDAY 工作台，再到基础配置里检查启动入口设置。

## 看不到 Start Here

可能原因：

- 官方内容还没有刷新。
- 订阅频道被关闭。
- 官方内容目录被移动或删除。
- 旧版 `F.R.I.D.A.Y/` 内容阻止接管。

第一次使用时，不应该只依赖 Start Here。工作台里的新手引导会先带你完成工作范围和模型配置。

## 看不到订阅频道

可能原因：

- Git 不可用。
- 访问更新源需要的凭据未配置。
- 发布 feed 读取失败。
- `F.R.I.D.A.Y/` 下存在遗留内容，阻止接管。

先按订阅频道里的提示补齐凭据，再回到订阅频道刷新。Git 邮箱通常不是读取官方内容的必需项。

## 项目注册失败

先检查：

- 是否选择了工作文件夹。
- 项目名称是否为空。
- 目标路径是否已经存在同名文件。
- 是否把整个 Vault 作为项目但没有二次确认。
- 当前目录是否位于上层 Git 仓库里。

如果你选择 `/（在 Vault 根目录下新建同名文件夹）`，FRIDAY 会按项目名称在 Vault 根目录创建文件夹。

## 项目同步失败

先看同步页：

- 当前项目是否绑定远端。
- 分支是否正确。
- 工作区是否有未提交变更。
- 是否存在冲突。
- Git 令牌是否有仓库权限。

如果是冲突，不要重复点击同步，先处理冲突记录。

## FRIDAY 读不到我的文件

常见原因：

- 当前项目选错。
- 文件不在项目根目录下。
- Vault 聚焦路径限制了读取范围。
- 文件夹引用没有解析成功。

先确认工作台顶部的当前项目，再检查 `@` 引用结果。

## 已经能聊天，但不能改文件

常见原因：

- 当前权限模式需要你确认写入。
- 任务没有说清楚要改哪个文件。
- 目标文件不在当前项目边界内。
- 工具执行摘要里有等待确认的动作。

先展开工具执行摘要，确认写入目标和权限提示。

## 图片发送失败

可能原因：

- 当前模型不支持视觉输入。
- 图片超过大小限制。
- 网关不接受图片消息格式。
- 图片文件无法读取。

建议先裁剪图片，再做视觉能力测试。

## Skill 找不到

先输入：

```text
/skills
```

如果列表为空，检查设置里的 Skill 外路径，并确认路径下存在 `SKILL.md`。内置 Skill 不需要额外配置。

## 工具执行被拦截

标准权限模式会要求确认写入操作。严格模式会拦截更多工具。你可以在对话页临时调整权限，也可以在设置里修改默认权限模式。

> [!tip]
> 排查时优先看三件事：当前项目、LLM 连通状态、工具执行摘要。大多数问题都能从这三处定位。
