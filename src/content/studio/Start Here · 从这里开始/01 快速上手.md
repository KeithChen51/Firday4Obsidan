# 快速上手

新手引导部分已经确保你可以和FRIDAY对话了，因此这里主要是回顾这个流程中主要涉及哪些流程，我们做了什么。
![[assets/01-01.png|720]]
首次打开 FRIDAY 时，你会看到一个简要的启动引导。


- 选择一个文件夹：告诉 FRIDAY 可以在哪个范围内读取、写入和理解资料。
- 配置模型：让 FRIDAY 可以真正开始回复你。

这两步完成后，对话页就可以工作。Git、同步、官方内容订阅、Skill 扩展、Wiki 编译都可以之后再慢慢配置。

## 1.1 选择一个文件夹

在 FRIDAY 中，AI 根据我们配置的根目录（也就是你选择的文件夹）来确定工作范围。这个范围通常是 Vault 里的某个项目文件夹，也可以是你之后准备长期维护的一组笔记。

选择文件夹后，FRIDAY 会把它作为当前项目。这样做有三个目的：

- 对话时默认围绕这个项目理解上下文。
- 使用 `@ 文件夹` 或 `@ 笔记` 时，优先在项目边界内解析。
- 执行读写操作时，不会随意触碰项目外的内容。

如果你一开始没有现成项目，可以选择在 Vault 根目录下新建同名文件夹。这样你可以先开一个干净的工作区，之后再逐步放入资料。

> [!tip]
> 项目不等于 Git 仓库。你可以只把它当作 FRIDAY 的工作范围，先用来对话和整理笔记。

## 1.2 配置模型

模型配置决定 FRIDAY 能不能回答你。这里通常需要填写：

- API 地址。
- 模型名称。
- API 密钥（仅OpenAI协议模式）。
![[assets/01-02.png|720]]
由于前期大家都配置了OpenCode，并有自己的key，我建议大家直接选集采模式，然后一键同步OpenCode的配置。
![[assets/01-03.png|720]]
配置完成后，建议先做一次连通测试。测试通过，说明 FRIDAY 已经能把你的问题发给模型并收到回复。

如果你暂时只想看看界面，不配置模型也可以继续浏览工作台、设置和这套指南。但只要要开始对话，模型就是必需项。

更完整的配置说明见 [[02 基础配置]]。

## 第三步：开始第一轮对话

完成工作范围和模型配置后，对话页会成为主要入口。你可以先从很小的任务开始，例如：

```text
总结当前笔记，并列出三个行动项。
```

```text
检查这个文件夹里最需要我补充说明的地方。
```

```text
帮我把这篇笔记整理成更清楚的结构，不要直接覆盖原文。
```

刚开始不要急着让 FRIDAY 一次完成很复杂的工作。先用小任务确认三件事：

- 当前项目选对了。
- 模型回复正常。
- FRIDAY 能读到你希望它参考的资料。

对话能力的详细说明见 [[05 和 FRIDAY 对话]]。

## 刚才没有配置的内容

新手引导刻意没有要求你一次填完所有设置。下面这些内容都可以之后再补：

| 内容 | 什么时候需要 |
| --- | --- |
| Git 用户名、邮箱、令牌 | 需要远端同步、访问私有仓库或刷新需要凭据的官方内容时 |
| 自动同步 | 已经确认项目远端和忽略规则正确后 |
| 官方内容订阅 | 需要刷新 Start Here、官方教程和图片资源时 |
| Skill 外部路径 | 需要接入你自己的自定义 Skill 时 |
| Soul 和默认模型策略 | 想调整 FRIDAY 的说话风格、协作方式或默认模型时 |

- [[05 和 FRIDAY 对话]]：学习如何引用笔记、发送图片和连续下指令。
